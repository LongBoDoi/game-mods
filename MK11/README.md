# Mortal Kombat 11 mods

| Mod | What it does |
|---|---|
| [MK11Tweaks](MK11Tweaks/) | F1 panel with offline cheats: unlimited health and meters, weak opponents (adjustable), unlimited Fatal Blows and Krushing Blows |

**Install:** download `MK11-v*.zip` from the release, extract it anywhere, and double-click `Install.cmd` with the game closed. It finds the game through Steam, then copies `MK11Tweaks.asi` and the Ultimate ASI Loader (`dinput8.dll`, only if it's missing) into `Binaries\Retail`. `Uninstall.cmd` removes the mod.

Play the **DirectX 11** version (`MK11.exe`). **Offline only:** don't use it online or in Towers of Time (leaderboards).
