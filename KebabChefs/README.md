# Kebab Chefs! - Restaurant Simulator mods

| Mod | What it does |
|---|---|
| [PlayerTweaks](PlayerTweaks/) | F1 overlay: movement and reach, teleports, multi-pick, place-all, store hold-repeat, skip fish cutting, plate cabinets, thief-cat schedule, dish-status overlay, menu presets and more |
| [LoadTweaks](LoadTweaks/) | Makes heavy saves load faster by drawing fewer frames during the load; F8 shows a load-time breakdown |

**Install:** download `KebabChefs-v*.zip` from the release, extract it anywhere, and double-click `Install.cmd` with the game closed. It finds the game through Steam, downloads BepInEx 6.0.0-be.785 (IL2CPP) if it's missing, and installs both mods. The first launch after installing BepInEx takes several minutes on a frozen-looking screen, while BepInEx generates its interop assemblies. `Uninstall.cmd` removes the mods (add `-RemoveConfig` to delete their settings too).

**Settings:** `BepInEx\config\com.manhl.kebabchefs.*.cfg` (created on first launch).
