# Lemon Cake mods

| Mod | What it does |
|---|---|
| [LemonCoop](LemonCoop/) | Local 2-player split-screen co-op with gamepads: each player gets their own room camera, and money and XP are shared |

**Install:** download `LemonCake-v*.zip` from the release, extract it anywhere, and double-click `Install.cmd` with the game closed. It finds the game through Steam, installs UE4SS v3.0.1 if it's missing, installs the mod and enables it in `mods.txt`, and adds a small patch pak with the gamepad bindings. `Uninstall.cmd` removes the mod and the pak.

**Before playing:** turn **Steam Input off** for Lemon Cake (Steam → Lemon Cake → Properties → Controller → "Disable Steam Input"). Player 2 joins automatically once you're in the game; by default the first gamepad is player 2 and player 1 uses keyboard and mouse. Keys: F1 split layout · F2 join · F3 remove player 2 · F4 teleport player 2 to player 1 · F8 dual monitor.
