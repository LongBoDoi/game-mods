# Game Mods

My mods for various games, one folder per game.

| Game | Mod | What it does | Loader |
|---|---|---|---|
| [Bone's Cafe](BonesCafe/) | [HoldAct](BonesCafe/HoldAct/) | Hold Act (chop, grind…) to repeat it quickly instead of mashing the button | BepInEx 5 |

## Layout

```
<Game>/
  <Mod>/
    README.md      how to install and configure
    ...source...
    dist/          installer scripts (built DLLs are attached to GitHub Releases)
```
