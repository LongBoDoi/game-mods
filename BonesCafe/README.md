# Bone's Cafe mods

| Mod | What it does |
|---|---|
| [HoldAct](HoldAct/) | Hold **Act** (J / gamepad X) to keep chopping and grinding, 10 times a second instead of the game's 4 |

**Install:** download `BonesCafe-v*.zip` from the release, extract it anywhere, and double-click `Install.cmd` with the game closed. It finds the game through Steam, installs BepInEx 5 if it's missing, and installs the mod. `Uninstall.cmd` removes the mod.

**Settings:** `BepInEx\config\manhl.bonescafe.holdact.cfg` (created on first launch).
