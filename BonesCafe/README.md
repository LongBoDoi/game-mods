# Bone's Cafe mods

| Mod | What it does |
|---|---|
| [BonesTweaks](BonesTweaks/) | In-game panel (**F1**, Vietnamese) with two switchable tweaks: **fast Act hold** (holding J / gamepad X keeps chopping and grinding, 4–20 times a second instead of the game's 4) and **infinite ingredients** (the fridge's premium ingredients never run out). Both start off. |

**Install:** download `BonesCafe-v*.zip` from the release, extract it anywhere, and double-click `Install.cmd` with the game closed. It finds the game through Steam, installs BepInEx 5 if it's missing, installs the mod, and removes the old HoldAct plugin from v1.0. `Uninstall.cmd` removes the mod.

**Leaderboards:** once a tweak has been on, the game's uploads to the online leaderboards are skipped until you restart the game.

**Settings:** saved from the panel to `BepInEx\config\manhl.bonescafe.tweaks.cfg`.
